# Grupp 5 Gruppuppgift
## Medlemmar
Ola Aldaini, Elljas Andersson, Robin Eriksson
## Funktioner
Webbplatsen visar en meny med pizzor och innehåller en knapp som låter användaren slumpa fram en pizza om den inte kan bestämma sig.
## Instruktioner
Öppna sidan genom att öppna index.html i valfri webbläsare för att läsa. Tryck på knappen för att slumpa en pizza.
## Beskrivning av arbetet
Vi delade upp arbetet genom att skapa issues och tilldelade varje medlem var sin issue. Vi utförde sedan arbetet individuellt och gjorde pull requests som vi lät en annan medlem granska innan vi gjorde en merge till main.

Vi fick en konflikt för feature/text när den skulle mergas till main eftersom feature/issue-3-knapp redan hade mergats och båda hade ändrat index.html. feature/text innehöll gammal text i knappen medan feature/issue-3 hade en gammal version av resten av sidan. Konflikten löstes genom att använda githubs konfliktredigerare för att ta bort den gamla texten från main och den gamla knappens text från feature/text.

Vi kontrollerade sedan att sidan fungerade efter alla ändringar.
